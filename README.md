# C++ Module 00 — C++ Fundamentals

C++98 exercises in console I/O, basic classes, and encapsulation.

## In this repository

- `ex00` — Megaphone turns command-line arguments into uppercase output.
- `ex01` — PhoneBook stores and searches contacts from an interactive prompt.

## Build and run

```sh
make -C ex00
./ex00/megaphone "Hello, world!"
make -C ex01
./ex01/PhoneBook
```

The phone book accepts `ADD`, `SEARCH`, and `EXIT`.
